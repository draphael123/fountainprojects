📖 How to Use

  • Search: Type in the search bar to find projects by name, description, owner, or tags
  • Filter: Click status buttons to filter projects by their current status
  • Sort: Click column headers in table view to sort projects
  • View Toggle: Switch between table and card views using the view buttons
  • Quick View: Click any project row/card to see details without editing
  • Bulk Actions: Select multiple projects using checkboxes for bulk operations
  • Progress Tracking: Update progress percentage to track completion
  • Tags: Add comma-separated tags to categorize and find projects easily

💡 Tips

  • Use tags to group related projects (e.g., "automation", "frontend", "api")
  • Set due dates to track deadlines and see overdue projects highlighted
  • Export your data regularly as a backup
  • Archive completed projects to keep your active list clean
  • Use priority levels to focus on high-impact projects first
